# xuchar(3) — Unicode Character String Utilities

**Author:** MrR736
**License:** GNU GPLv3+

## Overview

`xuchar.h` provides a family of null-terminated string utilities for three character-unit types:

- `char8_t` — UTF-8 code units.
- `char16_t` — UTF-16 code units.
- `char32_t` — UTF-32 code units.

The API follows familiar C string-library conventions while providing parallel functions for each character type. The `ustr8`, `ustr16`, and `ustr32` prefixes distinguish the respective interfaces.

**Important:** String lengths and bounded operations are measured in character units, not necessarily Unicode code points or grapheme clusters. For UTF-8, lengths are measured in bytes; for UTF-16, they are measured in 16-bit code units; for UTF-32, they are measured in 32-bit code units.

## Include

```c
#include "xuchar.h"
```

## Character Types and Naming

| Prefix | Character type | Unit |
|---|---|---|
| `ustr8` | `char8_t` | UTF-8 byte |
| `ustr16` | `char16_t` | UTF-16 code unit |
| `ustr32` | `char32_t` | UTF-32 code unit |

Each function is available under all three prefixes. For example, `ustr8len()`, `ustr16len()`, and `ustr32len()` provide the corresponding length operations.

The `char8_t` type in this library may be a project-defined typedef. In C++11, ordinary and `u8` string literals have type `const char[]`; they cannot directly initialize arrays of `char8_t` when that type is `unsigned char`.

## Functions

The following declarations are generated by the header's declaration macro. The examples use the `ustr16` prefix where practical; the same function families are available with `ustr8` and `ustr32`.

### `ustr8len()`, `ustr16len()`, `ustr32len()`

```c
size_t ustr8len(const char8_t *s);
size_t ustr16len(const char16_t *s);
size_t ustr32len(const char32_t *s);
```

Return the number of character units before the terminating null unit.

**Parameters**

- `s` — Pointer to a null-terminated string, or `NULL` if the implementation supports null input.

**Returns:** The number of character units, excluding the terminator.

### `ustr8nlen()`, `ustr16nlen()`, `ustr32nlen()`

```c
size_t ustr8nlen(const char8_t *string, size_t maxlen);
size_t ustr16nlen(const char16_t *string, size_t maxlen);
size_t ustr32nlen(const char32_t *string, size_t maxlen);
```

Measure a string up to `maxlen` units.

**Returns:** The number of units before a null unit or before `maxlen` units have been examined.

### Copying and Concatenation

```c
char8_t  *ustr8cpy(char8_t *dest, const char8_t *src);
char8_t  *ustr8ncpy(char8_t *dest, const char8_t *src, size_t n);
char8_t  *ustr8cat(char8_t *dest, const char8_t *src);
char8_t  *ustr8ncat(char8_t *dest, const char8_t *src, size_t n);
```

Equivalent functions exist for `char16_t` and `char32_t`.

- **`cpy()`** copies the source string, including its terminator.
- **`ncpy()`** copies at most `n` units. Whether it pads the destination with null units when the source is shorter must follow the implementation's documented semantics.
- **`cat()`** appends the source string to the destination.
- **`ncat()`** appends at most `n` source units and, under conventional bounded-concatenation semantics, writes a terminating null unit.

The destination must have enough space for the resulting string. Source and destination must not overlap if the implementation follows the declared `restrict` contract.

**Returns:** The destination pointer.

### Comparison

```c
int ustr8cmp(const char8_t *s1, const char8_t *s2);
int ustr8ncmp(const char8_t *s1, const char8_t *s2, size_t n);
int ustr8coll(const char8_t *s1, const char8_t *s2);
```

Equivalent functions exist for UTF-16 and UTF-32.

- **`cmp()`** compares two strings.
- **`ncmp()`** compares at most `n` character units.
- **`coll()`** compares strings according to the library's collation semantics.

**Returns:** A negative value if the first string compares less than the second, zero if they compare equal, or a positive value if the first compares greater.

The exact collation behavior of `coll()` depends on the implementation. Document whether it performs ordinal code-unit comparison or locale-sensitive collation.

### Case-Insensitive Comparison

```c
int ustr8casecmp(const char8_t *s1, const char8_t *s2);
int ustr8ncasecmp(const char8_t *s1, const char8_t *s2, size_t n);
```

Equivalent functions exist for UTF-16 and UTF-32.

Compare strings without regard to case, optionally limiting the comparison to `n` units.

**Returns:** A negative, zero, or positive value according to the comparison result.

The API declaration alone does not establish whether these functions support ASCII-only case conversion, locale-dependent behavior, or full Unicode case folding. Their implementation should define this explicitly.

### Duplication

```c
char8_t *ustr8dup(const char8_t *s);
char8_t *ustr8ndup(const char8_t *s, size_t n);
```

Equivalent functions exist for UTF-16 and UTF-32.

- **`dup()`** allocates and returns a copy of the string.
- **`ndup()`** allocates and returns a copy containing at most `n` source units.

**Returns:** A pointer to the allocated string, or `NULL` on allocation failure.

The returned allocation belongs to the caller and must be released using the allocator's matching deallocation function.

### Character Search

```c
char8_t *ustr8chr(const char8_t *s, int c);
char8_t *ustr8chrnul(const char8_t *s, int c);
```

Equivalent functions exist for UTF-16 and UTF-32.

- **`chr()`** locates the first occurrence of a character unit, including the terminating null unit when searching for zero.
- **`chrnul()`** locates the first occurrence of the requested unit or returns a pointer to the terminating null unit if no match exists.

**Returns:** A pointer to the matching unit, or `NULL` for an unsuccessful `chr()` search.

The declared return type is mutable even though the input is `const`. Callers should not modify data obtained from a pointer into a read-only string. A future API revision could improve const-correctness.

### Character-Set Search and Spans

```c
size_t ustr8cspn(const char8_t *s, const char8_t *reject);
size_t ustr8spn(const char8_t *s, const char8_t *accept);
char8_t *ustr8pbrk(const char8_t *s, const char8_t *accept);
```

Equivalent functions exist for UTF-16 and UTF-32.

- **`cspn()`** counts initial units in `s` that do not occur in `reject`.
- **`spn()`** counts initial units in `s` that all occur in `accept`.
- **`pbrk()`** locates the first unit in `s` that occurs in `accept`.

**Returns:** A count for the span functions, or a pointer to the matching unit for `pbrk()`. `pbrk()` returns `NULL` if no match is found.

### Tokenization

```c
char8_t *ustr8tok_r(
    char8_t *s,
    const char8_t *delim,
    char8_t **save_ptr);

char8_t *ustr8tok(char8_t *s, const char8_t *delim);
```

Equivalent functions exist for UTF-16 and UTF-32.

- **`tok_r()`** splits a mutable string into tokens and stores continuation state in `save_ptr`. It supports independent parsing states.
- **`tok()`** provides tokenization using internal state and is therefore unsuitable for independent or concurrent parsing sequences unless the implementation provides additional guarantees.

On the first call, pass the string to tokenize. On subsequent calls, pass `NULL` as the string argument to continue parsing.

**Returns:** A pointer to the next token, or `NULL` when no more tokens are available.

As with conventional `strtok()`-style APIs, delimiters are replaced with null units, and consecutive delimiters are normally skipped.

### Substring Search

```c
char8_t *ustr8str(const char8_t *haystack, const char8_t *needle);
char8_t *ustr8casestr(const char8_t *haystack, const char8_t *needle);
```

Equivalent functions exist for UTF-16 and UTF-32.

- **`str()`** locates the first occurrence of a substring.
- **`casestr()`** locates a substring without regard to case.

**Returns:** A pointer to the first match, or `NULL` if no match is found. Under conventional substring-search semantics, an empty needle matches at the beginning of the haystack.

Case-insensitive search behavior depends on the implementation's case-mapping rules.

### Transformation

```c
size_t ustr8xfrm(char8_t *dest, const char8_t *src, size_t n);
size_t ustr16xfrm(char16_t *dest, const char16_t *src, size_t n);
size_t ustr32xfrm(char32_t *dest, const char32_t *src, size_t n);
```

Transform `src` into a form suitable for subsequent comparison, subject to the implementation's transformation rules.

**Returns:** The required transformed length, excluding the terminating null unit, if the implementation follows the conventional `strxfrm()` contract.

When `n` is nonzero, `dest` must provide enough storage for the units the implementation writes. If the return value is greater than or equal to `n`, the destination may not contain the complete transformed string.

The exact transformation and collation relationship must be documented by the implementation. A transformation suitable for locale-aware collation is not necessarily a Unicode normalization operation.

## Examples

### UTF-16 string operations

```cpp
#include <iostream>
#include <cstdlib>
#include "xuchar.h"
#include "xmemory.h"

int main()
{
    const char16_t text[] = u"hello";
    const char16_t needle[] = u"ll";

    std::cout << "Length: " << ustr16len(text) << '\n';

    const char16_t *match = ustr16str(text, needle);
    if (match != NULL)
        std::cout << "Match offset: " << (match - text) << '\n';

    char16_t *copy = ustr16dup(text);
    if (copy == NULL)
        return 1;

    xfree(copy);
    return 0;
}
```

This example assumes that the library's allocation functions are compatible with `xfree()`. If `ustr16dup()` uses a project-specific allocator, release the returned pointer using its matching deallocator instead.

### UTF-8 string operations in C++11

If `char8_t` is defined as `unsigned char`, construct test data using correctly typed arrays:

```cpp
#include "xuchar.h"

int main()
{
    const char8_t text[] = {'h', 'e', 'l', 'l', 'o', 0};
    const char8_t suffix[] = {'l', 'o', 0};

    if (ustr8len(text) != 5)
        return 1;

    if (ustr8str(text, suffix) != text + 3)
        return 1;

    return 0;
}
```

For non-ASCII UTF-8, each byte must be represented in the correct encoding. For example, U+00E9 (`é`) is encoded as `0xC3, 0xA9`:

```cpp
const char8_t e_acute[] = {0xC3, 0xA9, 0};
```

## Safety and Correctness Notes

- Inputs to string operations must satisfy their documented null-termination and pointer-validity requirements.
- Bounded operations count code units, not complete Unicode characters. Truncating UTF-8 or UTF-16 at an arbitrary unit boundary can split an encoded character or surrogate pair.
- The `restrict` qualifiers indicate that overlapping source and destination regions are not permitted for the affected operations.
- Functions returning allocated memory require matching deallocation.
- Case-insensitive operations do not automatically imply full Unicode case folding.
- Collation and transformation behavior should be specified by the library implementation.
- Search functions declared with mutable pointer return types must not be used to modify data originally supplied through a read-only pointer.

## Thread Safety

Functions that operate solely on caller-provided strings and state can generally be used concurrently on independent data, provided their implementations use no shared mutable state.

`ustr8tok()`, `ustr16tok()`, and `ustr32tok()` may use internal tokenizer state. Use the corresponding `tok_r()` functions when independent parsing state is required. Actual thread-safety guarantees depend on the implementation.
